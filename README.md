# Mobile_Shopy_Management System

### Desktop Application Using C#.NET

### 📖 About the Project : 
The Mobile Shopy Management System Web Application is an integrated solution developed using ASP.NET MVC. The application is designed to handle Create , Read , Update , Delete Operations. 

The application uses Microsoft SQL Server as its database management system, ensuring robust data storage, querying capabilities, and scalability. The primary goal of the application is to offer a seamless experience for business owners and staff by enabling them to manage all operations.

### 🛠 Technologies Used:<hr>

Frontend: ASP.NET MVC

Backend: Microsoft SQL Server

IDE: Visual Studio
